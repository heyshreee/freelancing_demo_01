## 📖 Overview

An interactive portfolio and freelance showcase focused on a premium web experience — smooth GSAP animations, an horizontally-scrolled gallery, a cursor-driven interactive playground, and fully responsive behavior. No build step required.

![Freelancer Demo](freelancer-mov.gif)

## ✨ Features

- **Horizontal scroll showcase** — GSAP `ScrollTrigger`-pinned gallery on desktop.
- **Responsive by design** — vertical stacked panels on mobile, zig-zag splits on desktop.
- **Scroll-based reveals** — text, images, and CTAs animate on scroll.
- **Interactive playground** — 48 glowing grid orbs react to your cursor.
- **Mouse parallax** — hero content drifts subtly with pointer movement.
- **Smooth mobile navigation** — animated full-screen hamburger menu.
- **Scroll-to-top control** — quick, always-accessible button.

## 🛠️ Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| **HTML5** | Semantic, accessible page markup |
| **CSS3** | Layout, theming, and responsive styling |
| **JavaScript** | Interactivity and dynamic behavior |
| **GSAP + ScrollTrigger** | High-performance scroll & hover animations |
| **Tailwind CSS** (CDN) | Utility-first styling helpers |

## 🚀 Getting Started

This is a static project — there are no dependencies to install.

```bash
# 1. Clone the repository
git clone https://github.com/heyshreee/freelancing_demo_01.git

# 2. Navigate into the project
cd freelancing_demo_01

# 3. Open the page
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

> 💡 **Tip:** Use the **Live Server** extension in VS Code for a live-reload workflow.

## 🎨 Customization

- `index.html` — edit headings, copy, images, and links.
- `style.css` — adjust colors, typography, spacing, and breakpoints.
- `app.js` — tune animation durations, easing, and trigger thresholds.
