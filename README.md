# Freelancing Demo 01

A modern and interactive freelance showcase website built with HTML, CSS, JavaScript, and GSAP.

The project focuses on creating a premium web experience with smooth animations, responsive layouts, and interactive UI elements.

![Freelancer Demo](freelancer-mov.gif)

## 🚀 Technologies Used

- **HTML5** — Semantic and accessible page structure.
- **CSS3** — Custom styling, responsive layouts, and visual effects.
- **JavaScript** — Interactive functionality and dynamic behavior.
- **GSAP** — High-performance animations and motion effects.

## ✨ Features

- Smooth scrolling experience.
- Scroll-based reveal animations.
- Interactive UI elements.
- Responsive design for different screen sizes.
- Premium animated visual effects.
- GSAP-powered transitions and interactions.

## 🛠️ Setup & Usage

### 1. Clone the repository

```bash
git clone https://github.com/heyshreee/freelancing_demo_01.git
```

### 2. Navigate to the project

```bash
cd freelancing_demo_01
```

### 3. Run the project

No build process is required.

Simply open:

```text
index.html
```

in your preferred web browser.

For the best development experience, you can also use a local development server such as the **Live Server** extension in VS Code.

## 🎨 Customization

You can customize the project by modifying:

- `index.html` — Page structure and content.
- `style.css` — Layout, typography, colors, and visual styling.
- `script.js` — Interactions and GSAP animations.
